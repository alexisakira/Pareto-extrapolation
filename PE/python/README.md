# Pareto Extrapolation for Python

This directory contains the NumPy/SciPy implementation of the Pareto
extrapolation routines. The full mathematical and API documentation is in
[`../readme.tex`](../readme.tex).

Install the package and its test dependencies from this directory:

```console
python -m pip install -e ".[test,example]"
pytest
python examples/example.py
```
